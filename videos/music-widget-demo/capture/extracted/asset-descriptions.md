# Demo sources

- `widget-source.webm`: real English WPF MainWindow capture with actual YouTube search results and real stream playback through LocalPlayer. Transparent background. No personal desktop or saved-history list is recorded; longer network waits are omitted.
- `demo-track.wav`: original deterministic intro instrumental generated with seed 19042026.
- `hiraeth-demo.m4a`: licensed 32-second excerpt from the composer's official MP3, used for the edited export soundtrack only. See ASSET-LICENSES.md for CC BY 4.0 attribution.
- `capture-provenance.json`, `capture-frames.json`: recorded query, selected video, actual player positions, capture timing, and control state. No signed stream URLs are retained.
- `icon.png`: the repository's existing `docs/icon.png`, reused without redesign.
- `DemoSans-Regular.ttf`, `DemoSans-Bold.ttf`: Liberation Sans, supplied by the local fonts-liberation package. License copied alongside the fonts.

No website scrape, stock-photo service, hosted TTS, or paid generation is used.
