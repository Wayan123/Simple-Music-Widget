# Demo sources

- `widget-source.webm`: real WPF MainWindow capture using the real LocalPlayer, an original local WAV, and the application's own controls. Transparent background. No personal desktop or saved history is recorded.
- `demo-track.wav`: original deterministic instrumental generated by `tools/generate-audio.py` with seed 19042026. No sampled commercial music.
- `icon.png`: the repository's existing `docs/icon.png`, reused without redesign.
- `DemoSans-Regular.ttf`, `DemoSans-Bold.ttf`: Liberation Sans, supplied by the local fonts-liberation package. License copied alongside the fonts.

No website scrape, stock-photo service, hosted TTS, or paid generation is used.
